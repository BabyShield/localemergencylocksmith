- The connector returned only the partial batch preserved in `2026-08-29-locksmith-area-keyword-partial-uk.csv` before the account exhausted its available API units.
- Volumes are Semrush estimates for the exact keyword string. They are not local enquiry counts, rankings, or proof that an ambiguous place name refers to this service area.
- A recorded `0` is an explicit measured zero. No unreturned or unavailable query is represented as zero.

## Routing decision

The measured Southam, Studley and Alcester terms belong to their existing area hubs. No additional service-area page was created from these results. Stoke, Willenhall, Brandon and Whitley are geographically ambiguous at UK level, so their volumes were not used as evidence of demand for the local page.

The site therefore keeps the governed architecture: five separately written service sections on each area hub, with standalone service-area URLs only for the seven towns that already have evidence-reviewed pages. This snapshot does not justify publishing speculative duplicate or doorway pages.
